# Roadmap and support boundaries

## Remote Execution

<!-- feature: remote PARTIALLY_IMPLEMENTED -->

The workspace supports SSH profiles, pinned host keys, a Linux Worker, reconnection and file browsing. Distributed DAGs and Windows Workers remain planned. [Workspace guide](user-guide/workspace.md)

## Desktop language and help

<!-- feature: desktop-localization PLANNED -->

The desktop UI and most user-facing errors are currently Korean. The English guides include the Korean button labels. Potential work includes Korean/English selection, a persisted locale, translated errors and tooltips, and a Help action that opens the matching documentation.

## Setup and operational scope

<!-- feature: live-integration NOT_VERIFIED -->

Guided model setup, project registration and task planning are available. Direct provider APIs, automatic OAuth migration and native Windows and GPU integration verification remain pending.
