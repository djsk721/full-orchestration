# Orca workspace visual review

The review used all 12 [baseline application captures](orca-workspace-qa.md#baseline-native-captures) and the Orca screenshot supplied with the request. The reference makes the terminal the dominant activity, places project/session navigation alongside the workspace, and keeps contextual files accessible. Model Orchestration uses that organization with its own Tk components, theme, and confirmation flows.

| Priority | Baseline observation | Applied correction and evidence |
| --- | --- | --- |
| P0 | Split panes both used the same generic status and shortcut line. Their process names were available primarily in the left tree, with little visual focus feedback. | Each pane displays its session name and state. The focused PTY has an accent outline. [Baseline split](../assets/screenshots/orca-workspace/split-terminals-1920x1080.png) · [Installed CLI split](../assets/screenshots/orca-workspace/polish/installed-cli-split-1920x1080.png) |
| P0 | The earlier small capture was 1024×700. Long controls could compete with the center area at the minimum supported window size, and collapsing both side panels required using the layout menu twice. | The toolbar allows its view actions to wrap, and a visible Focus action hides both panels and remembers their previous state. The separate Files search remains reachable at 940×650. [Baseline Files view](../assets/screenshots/orca-workspace/project-files-small.png) · [940×650 Files view](../assets/screenshots/orca-workspace/polish/project-files-small.png) |
| P1 | The overview occupied the whole center with an empty, framed notes surface even for projects with no recent activity. The terminal launcher competed with project management for the next action. | The overview uses a bounded summary and a project-level terminal launcher. The View menu lists open tabs so a non-visible tab remains reachable. [Baseline overview](../assets/screenshots/orca-workspace/integrated-workspace-1440x900.png) · [Refined overview](../assets/screenshots/orca-workspace/polish/integrated-workspace-1440x900.png) |
| P1 | A session status could obscure the distinction between an interactive PTY and detached Worker or Supervisor execution. The Agent context and DAG were informative but visually similar to adjacent execution text. | Terminal pane headers identify the PTY, task progress identifies whether execution is detached, and Agent activity retains structured logs and stage navigation. [Agent context](../assets/screenshots/orca-workspace/polish/agent-context-1440x900.png) · [SSH terminal](../assets/screenshots/orca-workspace/polish/ssh-terminal-1440x900.png) |
| P1 | The remote project Git context had no diff view. The model picker showed configuration but longer model IDs were clipped in its narrow fixed field. | The context panel presents Worker status and scoped diff previews. The widened picker retains a full model identity in the status line, including for unusually long IDs. [Remote Git](../assets/screenshots/orca-workspace/polish/remote-git-1440x900.png) · [Model selector](../assets/screenshots/orca-workspace/polish/model-selector-1440x900.png) |
| P2 | Several workspace controls and modal prompts only had Korean text. The baseline light overview and read-only Electron history had consistent colors but different navigation density. | English and Korean cover the workspace, terminal, context panels, and integrated task dialogs. The separate Electron history surface continues to use its own read-only layout. [English light at 940×650](../assets/screenshots/orca-workspace/polish/english-light-940x650.png) · [English task form](../assets/screenshots/orca-workspace/polish/english-task-form.png) · [Electron history](../assets/screenshots/orca-workspace/electron-read-only.png) |

The 940×650 screenshots and widget geometry checks cover the supplied data and translated controls. Long project, tab, or model names can still be shortened in fixed-width views. The Xvfb host's Tk uses bitmap X11 fallback fonts. The native captures show that renderer directly and do not establish legibility for every OS font or scale. The [QA report](orca-workspace-qa.md) records the execution evidence separately.
