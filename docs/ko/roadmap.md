# 로드맵 및 지원 범위

## Remote Execution

<!-- feature: remote PARTIALLY_IMPLEMENTED -->

SSH 호스트와 지문 등록, Linux Worker 연결, 원격 작업 재연결 및 파일 탐색을 제공합니다. 분산 DAG와 Windows Worker는 남아 있습니다. [사용 방법](user-guide/workspace.md)

## UI 언어 및 도움말

<!-- feature: desktop-localization PLANNED -->

현재 Desktop의 UI와 사용자용 오류 메시지 대부분은 한국어입니다. 영어 가이드에는 실제 한국어 버튼을 함께 적었습니다. 이후 개발 범위에는 한국어/영어 설정, 저장된 언어로 재시작, 오류 및 툴팁 번역, 현재 언어의 문서로 이동하는 도움말이 포함됩니다.

## 설정 편의성과 운영 범위

<!-- feature: setup-ui PARTIALLY_IMPLEMENTED -->
<!-- feature: live-integration NOT_VERIFIED -->

양식 기반 모델 설정, 프로젝트 등록 및 가이드 작업 계획을 제공합니다. 공급자 직접 API, 자동 OAuth 이관 및 실제 Windows/GPU 운영 통합 검증은 남아 있습니다.
