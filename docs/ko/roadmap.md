# 로드맵 및 지원 범위

## Remote Execution

<!-- feature: remote PLANNED -->

SSH 인증, 호스트 관리, 원격 Workspace, Remote Worker, 원격 실행·로그·연결 복구를 위한 앱 기능은 없습니다. 현재 Workspace, Supervisor와 Git Worktree는 같은 호스트에 있습니다. 외부 HTTPS MCP 서버 접속은 도구 호출에 사용됩니다. 이 페이지의 향후 항목에는 일정이 확정되어 있지 않습니다.

## UI 언어 및 도움말

<!-- feature: desktop-localization PLANNED -->

현재 Desktop의 UI와 사용자용 오류 메시지 대부분은 한국어입니다. 영어 가이드에는 실제 한국어 버튼을 함께 적었습니다. 이후 개발 범위에는 한국어/영어 설정, 저장된 언어로 재시작, 오류 및 툴팁 번역, 현재 언어의 문서로 이동하는 도움말이 포함됩니다.

## 설정 편의성과 운영 범위

<!-- feature: setup-ui PLANNED -->
<!-- feature: live-integration NOT_VERIFIED -->

설치 마법사, 새 Git 저장소 생성, 양식 기반 Provider 편집 및 연결 테스트, MCP 연결의 GUI 토글, 자동 OAuth 이관, 하드웨어 실측과 분산 스케줄링은 현재 범위 밖입니다. Windows 배포 번들, 실제 GPU 및 외부 CLI 계정을 사용하는 통합 환경은 운영 환경에서 별도로 검증해야 합니다.
